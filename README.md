Zoom - Página Inicial

Projeto feito com HTML e CSS, recriando a página inicial do Zoom.

A página possui um menu de navegação, textos, imagens e botões, seguindo o visual do site original. Também utilizei Grid e Flexbox para organizar os elementos e Media Queries para adaptar o layout a telas menores.
Tecnologias utilizadas

    HTML5

    CSS3

    CSS Grid

    Flexbox

    Media Queries

Objetivo

Colocar em prática os conhecimentos de HTML e CSS, principalmente na criação e organização de layouts.
